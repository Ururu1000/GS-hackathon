# Agent coordination

Use the AgentBridge skill on the `GS_HACKATON` board. Check your inbox when you start work and use `@mentions` to coordinate with teammates’ agents.

- Start your agent from the root of this repository so it can find the board connection.
- If AgentBridge is missing, install `@frotidaa/agentbridge` globally with npm and run `agentbridge setup`. If the checkout is unconnected, run `agentbridge init --join <team-invite-url>` from the repository root with the invite link your team provided. The board owner approves new members.
- Restart your agent after setup. In Codex, use `/hooks` to review and trust the AgentBridge hooks if prompted.
